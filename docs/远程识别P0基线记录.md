## 2. 服务与进程基线（仓库可查）

- 启动链：`start_server.py` → `core/server/app.py:CapsWriterServer` → `ProcessManager`（识别 worker 子进程）+ `SocketManager`（WS 服务）+ 托盘。
- 识别进程此前无 PID 登记、无单实例互斥锁；本次起：启动时写 `logs/server.pid`（含进程创建时间）并持有命名互斥锁 `Local\CapsWriterOfflineASR`。
- 热词：服务端 `hot-server.txt` 在模型加载时一次性读取（无文件监听），网页改热词后需重启识别进程才生效。
- 日志：`logs/server_latest.log`（TruncatingFileHandler，10MB 截断，保留末 10 行）。

## 4. 本次改造的回滚点

- P1 之前：`git checkout codex/unified-client-live-preview` 即回旧客户端；服务端未改启动方式。
- P1 服务端鉴权默认 `auth_mode='lan_legacy'`：可信局域网直连沿用旧行为，旧客户端无需令牌即不受影响；要收紧改 `required`。
- 管理进程（P2/P3）独立于 ASR 运行，不启动管理进程即无任何行为变化；ASR 自身仍可双击 `start_server.py` 独立运行。
- 网页可写设置落在 `server_settings.json`（含 `.bak` 备份）；删除该文件即回到 `config_server.py` 默认值。
