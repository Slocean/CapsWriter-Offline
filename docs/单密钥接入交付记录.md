## 2. 代码改动摘要（对应执行文档 §3.A）

1. **客户端握手**（`core/client/connection/websocket_manager.py`）：远程接入发送 `X-API-Key: <面板Key>`，不再发送 `Authorization: Bearer`；局域网 `ws://` 继续可不填；重连、证书校验、语音协议未变。
2. **Key 语义与存储**（`config_client.py`、`credentials.py`、`desktop/CapsWriterDesktop.cs`）：字段更名 `server_token`→`api_key`，UI 更名「部署面板 API Key」，仍用当前 Windows 用户 DPAPI 存储（`%LOCALAPPDATA%\CapsWriterOffline\credentials.json`）。旧版 `cw.` 令牌：凭据存储中的旧键 `server_token` 仅用于检测，检测结果在 UI/日志提示重新录入，**绝不作为 Key 发送**；保存新 Key 时自动清除旧值。Key 不进配置文件、便携包、URL 或日志。
3. **服务端**（`config_server.py`、`server_manager.py`；删除 `auth.py`、`handshake.py`）：移除对外令牌校验、`auth_mode`、可信网段与网关标记配置；**保留**握手阶段连接数上限（503 拒绝）、单消息 64MB、帧队列上限与异常清理，未退回 `max_size=None`。磁盘上已有的 `server_tokens.json` 不会被自动删除（旧版回滚仍可用）。
4. **管理页**（`admin/`）：删除 `/api/v1/client-tokens` 接口与网页「客户端令牌」区；设置白名单移除「鉴权模式」。管理认证改为双模式：`password`（默认，原有密码登录，回滚可用）与 `gateway`（信任面板人用登录网关注入的用户请求头；切换前提是管理域名整站受网关保护且防火墙限制直连，见部署说明 §3）。CSRF/Origin、二次确认、审计、回环控制通道认证全部保留。
5. **日志脱敏**（`admin/logsource.py`）：新增 `X-API-Key:` 脱敏；`Bearer`、旧 `cw.` 令牌、`ctrl.` 控制令牌规则保留。
6. **打包与文档**（`desktop/package.ps1` 无需再改：新模块 `credentials.py`/`websocket_manager.py` 已在复制清单中）；`desktop/README.md`、`docs/远程识别部署与管理说明.md` 已按单密钥模型重写。

## 4. B 阶段：现场核对结果与已备好的产物（2026-09-29）

### 4.1 面板机制核对结论（只读，均以线上代码为准）

- 面板流水线**不能**把域名直连外部 Windows 上游：`src/panel/caddy/render.py:site_block` 对 api 流水线硬编码 `app-{pid}:{port}` → 必须走极薄网关容器方案（与开发计划 §3 预案一致）。
- 机器门（`apikey_gate`）按流水线配置 `{enabled, paths}`，Caddy `forward_auth` 携带调用方 `X-API-Key` 问面板 `/internal/authz/apikey`，按 Host+路径解析流水线；`/*` 可作整站路径。
- 面板 API Key 可直接调 API（`X-API-Key` 头，作用域：`read` / `pipeline:write`（POST /api/pipelines）/ `deploy`（upload/deploy）/ `gate:write`（POST /api/gate））。**密钥不能管理密钥**：给现有 Key 勾选站点授权（`gate.pid`）只能在面板 UI 做。
- `domains.json` 中 `voice.*` 未被占用；`voice.faiz.dpdns.org` / `voice-admin.faiz.dpdns.org` 可用。
- 服务器现状：ASR `6016` 从 WSL 可达（旧版无鉴权，机器门在面板层完成，**ASR 无需改动即可接入**）；管理端 `6017` 未运行；服务器 CapsWriter 安装为 PyInstaller 打包（`C:\Users\edc\Apps\CapsWriter-Offline-v2.6\runtime\`），Windows 侧无独立 Python（B3 部署管理进程的前置条件）。
