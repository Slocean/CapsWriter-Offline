# 远程识别与网页管理：部署与管理说明

> 对应开发计划：`docs/远程识别与网页管理开发计划.md`；基线记录见 `docs/远程识别P0基线记录.md`
> 域名与网关（P4）需在服务器现场执行；本文使用占位域名 `voice.faiz.dpdns.org` / `voice-admin.faiz.dpdns.org`
> 本文不包含任何真实令牌、密码或 Cloudflare 凭据

## 1. 组件与端口总览

| 组件 | 位置 | 端口 | 说明 |
| --- | --- | --- | --- |
| ASR 语音识别 | Windows（本仓库 `start_server.py`） | `0.0.0.0:6016` | 语音 WebSocket；握手鉴权默认 `lan_legacy` |
| 网页管理进程 | Windows（本仓库 `python -m admin`） | `0.0.0.0:6017` | 单页管理界面 + `/api/v1/`；独立于 ASR 进程 |
| ASR 控制通道 | ASR 进程内 | `127.0.0.1:6019` | 仅回环；管理进程专用（状态/优雅退出/日志级别） |
| 反代/隧道 | WSL Caddy + Cloudflare Tunnel | — | 由部署面板管理，勿手改 Caddyfile |

三个运行单元互不绑定死：ASR 崩溃时管理进程仍存活并可在网页上恢复；管理进程失效时原有局域网识别不受影响。

## 2. 服务端安装与更新

```powershell
# 在仓库根目录（识别服务所在机器）
git pull                      # 或解压新版
# 管理进程无新增第三方依赖（标准库 + 已有 websockets>=14,<18）

# 启动识别服务（原有方式不变）
python start_server.py

# 启动管理进程（首次启动自动生成管理员密码，只在控制台显示一次）
python -m admin --host 0.0.0.0 --port 6017
```

开机自启（二选一，不要同时启动两个模型实例）：

- 计划任务（推荐）：开机延迟 1 分钟执行 `python -m admin`，勾选「不管用户是否登录都要运行」。管理进程在启动后默认不自动拉起 ASR；在网页上点击「启动」即可，避免开机风暴。
- 延续原有方式：保留现有 `start_server.py` 开机任务，管理进程会通过 PID 文件/互斥锁自动识别已运行的 ASR（显示为在线或异常，绝不会拉起第二个实例）。

修改管理员密码：`python -m admin set-password`

## 3. 网页管理

浏览器打开 `http://<服务器IP>:6017/`（公网走管理域名）。

- **状态行**：在线/启动中/识别中/异常/已停止、模型、连接数、运行时长、内存、显存（不可用时明确标注）。
- **安全重启**：先显示活跃连接数并等待会话空闲（上限 120 秒），再优雅退出、重新拉起；「停止」按钮需要二次确认；强制中断走任务管理的 force 路径。
- **客户端令牌**：新建时填名称，明文只显示一次；支持轮换（旧令牌立即失效）与吊销。服务端只存哈希。
- **热词**：编辑 `hot-server.txt`，带冲突检测（他人先改过则 409）；保存后需重启识别进程生效（服务端在模型加载时读取热词）。
- **设置**：白名单字段（模型选择、日志级别、鉴权模式、对齐引擎空闲释放、GPU 预加速开关）；写入 `server_settings.json`（原子替换 + `.bak` 备份），改模型需重启。
- **日志**：5 秒增量轮询、可暂停；令牌等敏感字段自动脱敏；页面切到后台自动停发请求。
- **审计**：登录、令牌操作、设置修改、进程控制均有记录（`admin/data/audit.log`）。

## 4. 客户端令牌与远程连接

1. 管理页「客户端令牌」→ 新建（如“笔记本”）→ 复制明文（`cw.` 开头）。
2. 桌面客户端「服务器」卡片 → 选「远程 wss」→ 填完整地址（如 `wss://voice.faiz.dpdns.org`）→ 粘贴令牌 → 保存/测试连接。
3. 令牌以当前 Windows 用户 DPAPI 加密存于 `%LOCALAPPDATA%\CapsWriterOffline\credentials.json`，不进配置文件、不进日志、不进便携包；便携包复制到新电脑需重新录入。
4. 吊销/轮换后客户端会收到 HTTP 401，界面提示检查令牌。

鉴权模式（`auth_mode`）：

- `lan_legacy`（默认）：可信局域网直连沿用旧行为（免令牌）；凡经反代/网关转发的连接（带 `X-Forwarded-For` 等头）一律要求令牌。
- `required`：所有连接（含局域网）都必须持有效令牌。迁移完成后建议切换，管理页保存即时生效（对新连接）。

## 5. 公网发布（P4 现场执行清单）

按顺序执行，任一步失败先回滚该步：

1. **备份**：`config_server.py`、`hot-server.txt`、防火墙规则、面板路由、当前 `start_server.py` 启动方式。
2. **WSL 内验证**：容器内 `curl`/WS 握手到 `192.168.0.104:6016` 可达。
3. **面板创建流水线**：
   - 语音域名 `voice.*` → Windows `6016`（必须支持 WebSocket Upgrade，透传 Host 与超时配置）；
   - 管理域名 `voice-admin.*` → Windows `6017`。
   - 若面板不支持一条流水线绑两域名，拆两条。不手改 Caddyfile。
4. **管理域名先配 Cloudflare Access**（allow 指定管理员身份），确认非授权访问被挡，再让路由生效。管理进程自身仍校验密码会话（双保险）。
5. **Windows 防火墙**：新增规则只放行「WSL/网关来源 → 6017」；`6016` 既有 LAN 规则不动，也不映射 6016/6017 到路由器公网。WSL NAT 来源地址可能变化，跨 Windows/WSL 重启复测。
6. **验证门禁**（全部通过才切正式域名）：
   - 外网匿名连 `wss://voice.*` → 401 拒绝；
   - 带有效令牌的客户端 → 长按识别 + 按键开关识别各一次；
   - 未授权用户打不开管理页/读不到日志/改不了配置；
   - 原 LAN 客户端（未升级）仍可识别（`lan_legacy` 下）。

## 6. 故障排查速查

| 现象 | 排查顺序 |
| --- | --- |
| 客户端提示 HTTP 401 | 令牌错误/已吊销 → 管理页重新签发；或服务端切到 `required` 后 LAN 旧客户端未配令牌 |
| 管理页打不开（502） | 管理进程未运行 → RDP/SSH 后 `python -m admin`；检查面板路由与 Access 策略 |
| Cloudflare 1033 | Tunnel 离线 → 服务器上检查 cloudflared 与 WSL |
| 网页显示「异常/无响应」 | ASR 进程在但控制通道不通（如端口 6019 被占）→ 重启识别服务；PID 文件核对失败时管理页会明示 |
| 网页显示「已停止」但端口被占 | 其他进程占用 6016 → 管理进程拒绝启动新实例以免双实例，先处理占用 |
| 模型加载失败 | 看日志卡片具体原因（模型缺失/显存不足/端口占用/权限），处理后在网页点「启动」 |
| Windows 重启后 | 管理进程（计划任务）先起；ASR 按第 2 节两种方式之一恢复；网页刷新状态确认 |
| 令牌疑似泄漏 | 立即在管理页吊销该令牌 → 重新签发 → 更新客户端；不要为此关闭公网鉴权 |

## 7. 安全边界备忘

- 语音令牌：服务端只存 SHA-256 哈希，常数时间比较；明文只在创建/轮换响应出现一次；日志自动脱敏（`cw.*`、`Bearer`）。
- 管理会话：密码 PBKDF2 存储；Cookie HttpOnly + SameSite=Strict（HTTPS 下自动加 Secure）；写操作要求 CSRF 头 + Origin 同源；登录限速 5 次/分钟/IP。
- 控制通道：仅回环 + 独立令牌（`logs/server_control.token`），命令白名单（status/shutdown/set_log_level），不接受任意命令。
- 资源上限：单消息 64MB（文件转录 60s 分段约 5MB 的余量）、并发连接 8、每连接待处理帧队列有界；超限握手直接拒绝，不拖垮模型进程。
- 管理进程与 ASR 的进程核对：PID 文件含进程创建时间，杜绝 PID 复用误杀；单实例互斥锁 `Local\CapsWriterOfflineASR`。
