# CapsWriter 2.6.2：录音期间自动静音本机输出

【新增】
· 录音期间自动静音本机全部播放设备（扬声器/耳机/HDMI 等所有活动输出端点），松开/停止/取消的瞬间按设备逐台恢复原先的静音状态；麦克风与识别全程不受影响
· 覆盖全部录音触发路径：快捷键长按/单击、鼠标侧键、桌面客户端「开始录音」按钮、UDP 控制
· 录音期间插入/切换输出设备（如 HDMI 热插拔）、或被其他程序改变静音状态，都会在数百毫秒内被重新纳入静音范围，结束后同样按原值恢复
· 恢复遵循每台设备各自的先前状态：用户原本静音的设备不会被误解除，设备音量从不改动
· 默认开启，无需任何设置；如需关闭，可在 config_client.py 中将 mute_output_while_recording 设为 False
· 个别设备静音/恢复失败只记录日志，不阻断录音；程序退出时兜底恢复，不会把系统静音状态带走

【修复】
· 桌面端修改录音快捷键或启用开关现在立即保存并对运行中的客户端生效（此前仅更新界面显示，实际不生效）；保存结果有明确回执，未生效不会谎报成功
· 修复配置行内注释导致快捷键启用状态被误读为关闭的问题；刻意关闭的快捷键在升级后保持关闭
· 快捷键热应用采用事务式切换：重载期间统一防护键盘/鼠标/UDP 等一切开始路径，新快捷键监听确认就绪前旧快捷键保持可用，录音中的会话先按静音生命周期安全结束再切换；存在未完成的输出静音恢复时不报告成功；客户端重启兜底必须在新客户端日志确认快捷键登记后才报告生效

【说明】
· 静音的只是本机播放输出；录音采集（麦克风）设备的静音与音量全程保持原状
· 安装包与便携包由同一条 GitHub Actions 流水线从干净源码构建，附 SHA256 校验值、机器更新清单与本公告
