# CapsWriter 2.6.7：一键复制、浮窗置顶修复与实时声波

【新增】
· “识别文字”标题右侧增加“复制”按钮，点击即可复制全部识别内容，无需先选择文字；不受自动复制开关影响，成功后显示“已复制”。
· 录音浮窗采用横向细声波条，随麦克风真实音量向左滚动，右侧按钮结束录音。静音或音量数据过期时回落为细线，不再播放固定动画。
· 识别文字完整显示在声波下方，支持换行和滚动。收起状态开始录音时自动展开，结果返回后保持可见，便于查看。

【修复】
· 浮窗置顶同时校正 Windows 原生窗口层级，显示及状态刷新时恢复丢失的置顶状态，同时保持当前应用的输入焦点；关闭置顶开关立即取消置顶。
· 保留多段识别结果、手动选区、自动复制设置与浮窗收起偏好。

【发布】
· 客户端自动回归全部通过后再构建安装包与便携包；发布前验证便携包解压及安装、升级、卸载流程，附 SHA256 校验与更新清单。2.6.6 及更早版本可通过软件更新升级。
