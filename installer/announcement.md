# CapsWriter 2.6.3：管理端与桌面客户端界面整体焕新

【优化】
· 管理端网页与 Windows 桌面客户端采用同一套低饱和、克制的配色体系：中性底色、靛蓝主色，亮色/深色主题下均保持清晰对比
· 界面层级全面梳理：页面标题、分区标题、正文与辅助说明使用统一字号梯度，卡片、控件、日志区使用统一圆角与间距节奏
· 全部按钮补齐交互状态反馈：悬停、按下、键盘焦点环与禁用态，主/次/危险按钮样式在两端保持一致；输入框获得焦点时高亮描边
· 管理端状态总览更醒目：服务状态文字放大并配状态光环圆点，在线/启动中/已停止/异常一眼可辨；模型列表保留默认折叠细节与常显状态、操作
· 桌面端识别状态、服务器卡片、软件更新、浮窗（紧凑/展开）与运行记录全部套用新配色；录音中主按钮与浮窗停止方块在深色主题下对比更清晰
· 浮窗玻璃底色、连接状态圆点（已连接绿/未连接橙/录音红）语义与明暗主题统一

【修复】
· 手机宽度下管理端顶栏"主题/退出"按钮不再被挤压成两行：顶栏改为两行排布，按钮标签保持单行可辨识
· 桌面客户端最小窗口（640×560）下，快捷键行"启用"标签不再被右缘裁切
· 管理端模型列表长文件名与说明改为任意断行，不再把状态/大小/操作列挤出卡片；360–1920px 宽度均无横向溢出
· 150% 缩放屏下桌面客户端文字与控件渲染清晰不糊

【说明】
· 本次仅界面样式与呈现优化，无新增功能；录音、快捷键、静音、保存、连接与在线更新行为完全不变
· 安装包与便携包由同一条 GitHub Actions 流水线从干净源码构建，附 SHA256 校验值、机器更新清单与本公告
