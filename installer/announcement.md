# CapsWriter 2.6.6：识别文字可复制，自动复制与浮窗置顶开关

【修复】
· 识别文字框支持鼠标选择、Ctrl+A 全选、Ctrl+C 复制及右键复制；长文字可以滚动查看全文，不再只保留末尾 160 字。界面定时刷新时保留未变化文字的选区，方便复制。
· 显示经过热词与规则处理后的最终文字；边说边写时保留本次录音已完成的段落，避免草稿和最终结果重复拼接。

【新增】
· 设置 → 识别与快捷键设置：新增“识别完成后自动复制到剪贴板”开关，默认关闭。开启后，最终结果在输入及剪贴板恢复完成后自动复制；边说边写时复制本次录音全部已完成的段落，临时草稿、空结果和启动时的历史日志不会覆盖剪贴板。
· 设置 → 浮窗设置：新增“浮窗始终置于最顶层”开关，默认开启，可随时关闭。修改立即生效，两种浮窗布局均适用。
· 两个开关均自动保存，下次启动继续使用，无需重启客户端。

【发布】
· 安装包和便携包由同一条 GitHub Actions 流水线构建，附 SHA256 校验与更新清单。2.6.5 用户可通过软件更新升级到本版本。
