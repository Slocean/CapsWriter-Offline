# CapsWriter 2.6.0：GitHub Actions 一键构建发布 · 程序内热更新上线

【本次发布】
· 安装版（CapsWriter-Setup-2.6.0.exe）与便携版（CapsWriter-Portable-2.6.0.exe）全部由 GitHub Actions 从干净源码构建，不再依赖任何本机已有文件；每次发布附 SHA256 校验值、机器可读更新清单（CapsWriter-Update-Manifest.json）与本公告
· 两种形态均支持程序内热更新：主界面「软件更新」卡片或托盘菜单「检查更新」即可检查、查看中文更新公告、下载并自动应用；无需手动卸载重装
· 安装版升级自动覆盖到当前安装目录；便携版升级直接替换原来的单文件 EXE 并自动重启，配置、热词、界面偏好与 DPAPI 加密凭据全部保留
· 下载与替换前都对文件做 SHA256 双重校验，校验失败、更新包错误或旧版本一律拒绝执行；替换失败自动回滚到原文件，不会留下损坏的程序
· 客户端只包含客户端：不打包服务端、识别模型、管理面板或任何密钥

【连接服务器】
· 默认连接局域网服务 192.168.0.104:6016，开箱即用
· 公网 wss 远程接入：在「服务器 → 远程 wss」填入地址并录入部署面板 API Key（以当前 Windows 用户 DPAPI 加密保存，不写入配置或日志）

【兼容说明】
· 从旧版安装包升级即可保留全部设置；便携版历史录音等大文件仍保留在旧版本缓存目录，不会丢失
