# CapsWriter 2.6.1：热更新可靠性修复

【修复】
· 便携版更新后的残留文件清理现在只处理本程序自己的文件；此前按通配名清理，可能误删同目录下其他程序同模式命名的文件
· 便携版更新失败回滚后，错误日志不再被随后的清理删除，便于反馈问题
· 安装版更新失败时更可靠地恢复旧版本并重新启动（覆盖安装程序无法启动、重启目标异常等边界均已覆盖）

【说明】
· 安装包与便携包由同一条 GitHub Actions 流水线从干净源码构建，附 SHA256 校验值、机器更新清单与本公告
· 本版本为首个正式发布版本；之后新版本发布后，可在程序内「软件更新」或托盘「检查更新」直接升级，无需手动重装
· 客户端默认连接局域网服务 192.168.0.104:6016；公网 wss 接入在「服务器 → 远程 wss」填地址并录入部署面板 API Key（当前 Windows 用户 DPAPI 加密保存）
